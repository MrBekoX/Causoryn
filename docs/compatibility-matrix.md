# Uyumluluk Matrisi — Host × Sonuç

> **Dil / Language:** **Türkçe** | [English](en/compatibility-matrix.md) · [Dokümantasyon Merkezi](README.md)

> **Durum:** Causoryn 0.3.2'i yansıtır (11 araçlık varsayılan `core` araç profili). Aşağıdaki matristeki canlı host CLI koşumları, `tools/list` çağrısının 29 araçlık kataloğu döndürdüğü 0.3.0 öncesinde kaydedilmiştir; 0.3.0 araç profilleri host CLI'larının yeniden koşulmasıyla değil, otomatik testlerle kapsanır (bkz. [Araç profilleri (0.3.0)](#araç-profilleri-030)).

> Kanıt: host kılavuzları [Claude Code](hosts/claude-code.md), [Codex](hosts/codex.md), [ZCode](hosts/zcode.md), [Antigravity](hosts/antigravity.md) ve `integrations/zcode/causoryn/README.md`. Uygulanan kurallar: koşulmayan bir smoke adımı `NOT RUN` olarak raporlanır (hiçbir zaman başarılı sayılmaz) ve smoke testleri bir geliştiricinin gerçek host yapılandırmasında kalıcı değişiklik bırakmaz. Bu sayfayı `tests/release-docs.test.ts` korur: Antigravity satırı `NOT RUN` kalmalıdır ve ZCode satırı yalnızca manifest ile izole CLI doğrulaması iddia edebilir.

**Motor kimliği:** `causoryn@0.3.2`, stdio üzerinden MCP (`@modelcontextprotocol/sdk` 1.32.2, envelope `schemaVersion: "2.0"`). Tarihsel koşumlar `causoryn@0.1.0` (2026-11-08/10) ve `0.2.x` paketli CLI (2026-11-19) ile kaydedildi.

**Araç profilleri:** `--tool-profile <list>`, `CAUSORYN_TOOL_PROFILE` veya `CAUSORYN_CONFIG.toolProfile` ile başka bir profil seçilmedikçe `tools/list` varsayılan **11 araçlık `core` profilini** yayımlar (öncelik bu sıradadır; varsayılan `core`). `wiki` 7 Living Wiki aracı, `history` 2 mimari geçmiş aracı ekler; profiller virgülle birleştirilir (`--tool-profile wiki,history`) ve `full`, yerini başka araçlara bırakan legacy araçlarda kullanımdan kaldırma notlarıyla birlikte tüm **32** aracı (29 legacy ad artı `causoryn_status`, `causoryn_trace`, `causoryn_contracts`) yayımlar. `causoryn setup` her host için `<node> <runtime>/scripts/causoryn.mjs mcp --allow-cwd --auto-data-dir --client <id>` komutunu kaydeder; bu yüzden her host `core` ile başlar. Başka bir profil kullanmak için `causoryn setup --tool-profile <list>` komutunu yeniden çalıştırın, kayıtlı argümanlara `--tool-profile …` ekleyin veya host'un sunucu ortamında `CAUSORYN_TOOL_PROFILE` değişkenini ayarlayın (`setup`'ı yeniden çalıştırmak bu düzenlemeleri korur). Bkz. [MCP Araç Sözleşmeleri](tool-contracts.md).

**Her yerde aynı motor:** npm dağıtım paketi `packages/causoryn` (`npx causoryn setup`) ve monorepo bundle'ı (`packages/mcp-server/dist/mcp-server.mjs` + `dist/index-worker.mjs` + vendored `node_modules/better-sqlite3/`) aynı motoru çalıştırır. Native `.node` eklentisi JavaScript içine gömülemediği için bundle bilinçli olarak çok dosyalıdır. Aynı makinedeki tüm host'lar workspace başına tek bir SQLite WAL veritabanını paylaşır (`<base>/workspaces/<slug>-<hash12>/graph.sqlite`, taban önceliği ZCode dahil her host için `--data-dir` > `~/.causoryn`; `ZCODE_PLUGIN_DATA` yalnızca `~/.causoryn` kullanılamadığında yedek); `--client` yalnızca tanısal bir etikettir ve `build_leases` tablosu iki host'un aynı anda snapshot yayımlamasını engeller.

**Doğrulama ortamı:** canlı host koşumları Windows x64 (build 10.0.26300), Node.js ≥ 24 üzerinde yapıldı. 3-OS GitHub Actions matrisi (`.github/workflows/ci.yml`: `ubuntu-latest`, `windows-latest`, Intel `macos-26-intel`; gece koşusu Apple Silicon `macos-26` ekler) build, paket, güvenlik ve test kapılarını üç işletim sisteminin tamamında koşar.

## Dürüstlük Notları

1. **Üç CLI host'undan ikisi host CLI'ı koşularak doğrulandı; Antigravity `agy` CLI'ı koşulamadı.** Bu nedenle host kurulum kapsamı 2/3 olarak raporlanır; kalan host açıkça `NOT RUN` durumundadır ve [Antigravity kılavuzunda](hosts/antigravity.md) koşulmaya hazır bir kontrol listesi bulunur.
2. **ZCode satırı manifest doğrulaması ve izole CLI yapılandırmasıyla sınırlıdır.** ZCode pazaryeri kurulumu yalnızca GUI üzerinden yapılır ve smoke testleri bir geliştiricinin gerçek ZCode kurulumunda değişiklik bırakmamalıdır. Kurulum talimatları ([ZCode kılavuzu](hosts/zcode.md), `integrations/zcode/causoryn/README.md`, `npx causoryn setup --client zcode --yes`) belgelenmiştir; etkileşimli masaüstü kurulumu `NOT RUN` olarak kalır.
3. **stdout hijyeni iki katmanda denetlenir.** Dört host'un tamamı aynı motoru başlattığından süreç düzeyindeki stdout disiplini host'lar arasında geçerlidir (birim paketi, güvenlik paketindeki 5 bağımsız spawn oturumu, Claude Code ve Codex manuel koşumları, `.tgz` E2E). Canlı host gözlemi yalnızca Claude Code ve Codex üzerinde yapıldı.
4. **Canlı host koşumları 0.3.0 öncesine aittir.** Bu koşumlar 29 araçlık kataloğu gözlemledi. 11 araçlık `core` varsayılanı ve diğer profiller yukarıda listelenen otomatik testlerle doğrulanır; Claude Code ve Codex smoke'unun 0.3.0 ile tekrarı burada kayıtlı değildir.
5. **Platform sınırı.** Canlı host CLI koşumları Windows x64 üzerindeydi. CI her build, paket, lint, secret taraması ve test kapısını `ubuntu-latest`, `windows-latest` ve `macos-26-intel` üzerinde koşar (Apple Silicon `macos-26` gece koşusunda); canlı etkileşimli macOS / ARM64 host smoke'u `NOT RUN` olarak kalır ve açık bir `1.0.0` kapısıdır.
6. **Parite sınırı.** Host'lar arası parite MCP araç şemaları ve sözleşme testleriyle tanımlanır. Eşdeğer host UI'ı veya izin davranışı iddia edilmez ve Causoryn bir host modeline araç seçtiremez.
