# Sprint-7 F6 — Güvenlik Turu: Paketlenmiş Bundle (TŞ §22 Matrisi)

> Kanıt: raw/Causoryn_Teknik_Dokuman_v2.1.pdf s.22 §22 "Security: symlink/path traversal, secret leakage, symlink TOCTOU, poisoned source comment, oversized files, malicious Git refs, network denied" + s.21 §19 tehdit modeli + s.22 §20 konfigürasyon güvenli default'ları · wiki/sprint-7.md F6 · wiki/decisions.md K-008/K-011/K-012/K-014/K-015/K-016.

## Kapsam ve yöntem

Hedef artefakt, F1'in **paketenmiş bundle çıktısıdır**: `packages/mcp-server/dist/mcp-server.mjs` + `dist/node_modules/better-sqlite3/` (vendored native çalışma zamanı).

- **Bundle kimliği:** sha256 `7f7a59a8a9cebb797d89e2744a1720a71b1aa154ccbb535e7cb621e6db3354ba` — `dist/bundle-manifest.json` (33 dosya, sıralı sha256; aynı çıktı `integrations/antigravity/causoryn/scripts/` altına da deterministik sahnelenir) ile birebir eşleşir (`node -e` karşılaştırması: `hash match: true`).
- **Üretim komutu:** `node scripts/build-bundle.mjs` (`npm run build:bundle` ile aynı); determinizm F1 suite'inde (iki build bit-bit aynı) kanıtlanmıştır.
- **Davranışsal testler** bundle'ı GERÇEK child process olarak spawn eder (InMemoryTransport değil): `tests/security-release/helpers/bundle-client.ts` — MCP `initialize` + `notifications/initialized` el sıkışması, NDJSON JSON-RPC satır-tamponu, tüm stdout/stderr satırları sızıntı taramasına açık.
- **Korunan klon disiplini (takım denetimi bulgusu 4 sonrası):** davranışsal oturumların spawn ettiği dosya ile statik taramaların okuduğu dosya TEK korunan klon anlık görüntüsüdür (`cloneBundleTo`: mcp-server.mjs + node_modules + bundle-manifest.json, yarış penceresine karşı 5 denemeli yeniden üretim). `F6-K0` kimlik-bağlama testi, klonun manifest sha256 girişlerinin TAMAMIyla birebir eşleşmesini ve spawn kaynağıyla bayt-kimliğini doğrular — koşut rebuild penceresinde yırtık/yarım kopya KIRMIZI düşer (kırmızı kanıt: manifest kopyası eklenmeden önce K0+K1 ENOENT ile düştü).
- **Statik taramalar** bundle + vendored dosyaların tamamını (binary dahil) tarar.
- **Algılayıcı dürüstlüğü:** her statik tarayıcı için CANARY self-test'i vardır — algılayıcı ekili örnek kalıbı yakalamadan yeşil sayılmaz (kırmızı-yeteneği kanıtı). TDD akışı: yeni kabul ölçütleri önce yazıldı (failing test), algılayıcılar canary ile kırmızı-kanıtlandı; davranışsal testler yem (bait) işaretleriyle "regresyonda kırmızıya düşer" biçimde kurgulandı.
- **2026-11-10 yeniden doğrulama:** bu turdaki TÜM satırlar bağımsız bir oturumda TEKRAR koşuldu — bundle kimliği (`sha256` + manifest match), F6 paketi (32 test), `tests/security-release/` tamamı (36 test), tamamlayıcı suite'ler (100 + 57 test), statik grep taramaları (secret/network/shell/URL) ve `tsc -p tsconfig.typecheck.json` — hepsi bu belgedeki güncel rakamlarla yeşil. Aynı turda matris 6. satırı kaynak-düzeyi suite'lerden **bundle-düzeyi davranışsal kanıta** (F6-K7) yükseltildi: önceki turda git refs davranışı yalnızca kaynak workspace suite'lerinde koşuluyordu; K7 artık gerçek git commit'li fixture'la bundle spawn içinde `git cat-file` çözümlemesini ve `INVALID_REVISION` redlerini kanıtlar (kırmızı-yeteneği: git çözümlemesi çalışmasaydı POZİTİF dalın "ok" iddiası boşa düşerdi; NEGATİF dal çözümleme-başarısızlığından doğan `INVALID_REVISION`'ı zaten kırmızı kanıtlar).

Test üçlüsü: her kontrol satırında POZİTİF (politika içi çalışır) ve NEGATİF (politika dışı sabit kodla reddedilir) koşulları YÜRÜTÜLMÜŞ test kanıtıyla desteklenir; PARTIAL koşulu ya yürütülmüş sınır testidir ya da açıkça **(not)** etiketiyle işaretlenmiş yöntem/dokümantasyon notudur — ikisinin ayrımı tabloda görünür (takım denetimi bulgusu 5 sonrası netleştirildi).

## Dürüstlük notları (ADR-010)

1. **Paketleme fidelity bulgusu (F1 çıplak bundle vs `packages/causoryn` K-021 dağıtımı):** çıplak F1 bundle dizini (`packages/mcp-server/dist/`, 33 dosyalık manifest) TypeScript default lib dosyalarını (`lib.*.d.ts`) taşımaz; buna karşılık `K-021` ile açık kaynak dağıtım paketi `packages/causoryn` (`npm run build:package`), `dist/typescript-lib/lib*.d.ts` dosyalarını beraberinde sahneler ve `adapters/typescript` (`resolveTypeScriptLibDir`) bu dizini otomatik keşfederek izole kurulumlarda global tiplerle (`Promise`, `Record`, `Array`) tam `state: "ready"` üretir (`tests/open-source-distribution.test.ts`). Çıplak F1 klon testinde (`F6-K3`) ise `typescript-lib/` kopyalanmadığından global-referanssız fixture korundu; güvenlik davranışı her iki modda da eksiksiz geçerlidir.
2. **"Tek dosya" iddiası:** artefakt tek dosya DEĞİLDİR: `dist/mcp-server.mjs` + `dist/node_modules/better-sqlite3/` (32 dosya) — ADR-010 dürüstlüğüyle raporlanır (native .node gömülemez).
3. **`child_process` varlığı:** bundle'da meşru ve sıkı sınırlandırılmış `node:child_process` kullanım yüzeyi 7 modülden oluşur — (i) `packages/graph/src/git-read.ts` salt-okunur git (`execFile`, subcommand allowlist `cat-file`/`ls-tree`, `REF_PATTERN` doğrulaması), (ii) ortak sidecar IPC çekirdeği `packages/sidecar-ipc/src/index.ts` ve onu tüketen 4 dil sidecar adapter'ının `worker-process.ts` modülleri (`adapters/csharp-roslyn`, `adapters/python`, `adapters/go`, `adapters/rust` — literal komut + sabit argüman dizisi + env allowlist + `responseMaxChars`/`stderrMaxChars` bütçeleri; Go `go run` zaman aşımında sayısal çocuk PID üzerinde ağaç-kill), (iii) Rust toolchain yardımcısı `adapters/rust/src/cargo.ts` (`spawn`/`spawnSync` ile literal `cargo` probe/build + zaman aşımında sayısal çocuk PID üzerinde ağaç-kill). Tümünde shell interpolation sıfırdır (`shell: false`). F6-K7 (2026-11-10) git yüzeyini bundle spawn'da davranışsal olarak da kapatır (bkz. matris 6).
4. **URL dizgileri:** bundle metnindeki URL dizgileri dokümantasyon referanslarıdır (modelcontextprotocol spec, aka.ms/tsconfig, RFC'ler, ajv data.json, json-schema `$schema` tanımlayıcıları) — ağ çağrısı kapasitesiyle karıştırılmamalı; runtime sıfır ağ, netguard davranışsal testiyle kanıtlanmıştır. Ölçüm (2026-11-10 turunda tekrarlandı, aynı sonuç): `https://` 59 geçiş / 58 satır / 33 tekil URL, `http://` 21 geçiş — komutlar: `grep -o "https://" <bundle> | wc -l`, `grep -o "https://[a-zA-Z0-9./_-]*" | sort -u | wc -l`, `grep -c "https://" <bundle>`, `grep -o "http://" <bundle> | wc -l`.
5. **Kapsam sınırı:** K6 netguard kanıtı, koşulan oturumların (initialize → tools/list → index → export html → exit) kapsamındadır; bundle'ın tüm olası kod yollarının statik taramasıyla birlikte tamamlayıcı kanıttır.
6. **K7 fixture'ının git bağımlılığı:** POZİTİF dalın "SHA çözüldü" iddiası yalnızca gerçek bir git deposuyla anlamlıdır — "working-tree" alias'ı git'siz de çözülür (services-wiki.ts), bu yüzden ayırt edici kanıt gerçek commit SHA'sı üzerinden `git cat-file -t` koşusudur. Git'in çalıştığı ortamda NEGATİF dalın `INVALID_REVISION`'ı git'in GERÇEKTEN koşup çözümleyemediğini gösterir (sessiz başarı yoktur).
