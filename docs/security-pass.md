> Kanıt: raw/Causoryn_Teknik_Dokuman_v2.1.pdf s.22 §22 "Security: symlink/path traversal, secret leakage, symlink TOCTOU, poisoned source comment, oversized files, malicious Git refs, network denied" + s.21 §19 tehdit modeli + s.22 §20 konfigürasyon güvenli default'ları · wiki/sprint-7.md F6 · wiki/decisions.md K-008/K-011/K-012/K-014/K-015/K-016.

## Kapsam ve yöntem

Hedef artefakt, F1'in **paketenmiş bundle çıktısıdır**: `packages/mcp-server/dist/mcp-server.mjs` + `dist/node_modules/better-sqlite3/` (vendored native çalışma zamanı).

- **Bundle kimliği:** sha256 `c24ea12ca64eaf720134edebc468dbbb91b8af08b300c6d63f2f9261412bf8d6` — `dist/bundle-manifest.json` (33 dosya, sıralı sha256) ile birebir eşleşir (`node -e` karşılaştırması: `hash match: true`).
- **Üretim komutu:** `node scripts/build-bundle.mjs` (`npm run build:bundle` ile aynı); determinizm F1 suite'inde (iki build bit-bit aynı) kanıtlanmıştır.
- **Davranışsal testler** bundle'ı GERÇEK child process olarak spawn eder (InMemoryTransport değil): `tests/security-release/helpers/bundle-client.ts` — MCP `initialize` + `notifications/initialized` el sıkışması, NDJSON JSON-RPC satır-tamponu, tüm stdout/stderr satırları sızıntı taramasına açık.
- **Korunan klon disiplini (takım denetimi bulgusu 4 sonrası):** davranışsal oturumların spawn ettiği dosya ile statik taramaların okuduğu dosya TEK korunan klon anlık görüntüsüdür (`cloneBundleTo`: mcp-server.mjs + node_modules + bundle-manifest.json, yarış penceresine karşı 3 denemeli yeniden üretim). `F6-K0` kimlik-bağlama testi, klonun manifest sha256 girişlerinin TAMAMIyla birebir eşleşmesini ve spawn kaynağıyla bayt-kimliğini doğrular — koşut rebuild penceresinde yırtık/yarım kopya KIRMIZI düşer (kırmızı kanıt: manifest kopyası eklenmeden önce K0+K1 ENOENT ile düştü).
- **Statik taramalar** bundle + vendored dosyaların tamamını (binary dahil) tarar.
- **Algılayıcı dürüstlüğü:** her statik tarayıcı için CANARY self-test'i vardır — algılayıcı ekili örnek kalıbı yakalamadan yeşil sayılmaz (kırmızı-yeteneği kanıtı). TDD akışı: yeni kabul ölçütleri önce yazıldı (failing test), algılayıcılar canary ile kırmızı-kanıtlandı; davranışsal testler yem (bait) işaretleriyle "regresyonda kırmızıya düşer" biçimde kurgulandı.

Test üçlüsü: her kontrol satırında POZİTİF (politika içi çalışır) ve NEGATİF (politika dışı sabit kodla reddedilir) koşulları YÜRÜTÜLMÜŞ test kanıtıyla desteklenir; PARTIAL koşulu ya yürütülmüş sınır testidir ya da açıkça **(not)** etiketiyle işaretlenmiş yöntem/dokümantasyon notudur — ikisinin ayrımı tabloda görünür (takım denetimi bulgusu 5 sonrası netleştirildi).

## Dürüstlük notları (ADR-010)

1. **Paketleme fidelity bulgusu (yeni, güvenlik dışı):** bundle, TypeScript default lib dosyalarını (`lib.*.d.ts`) taşımaz — `build-bundle.mjs` karar notundaki "default lib konumu bundle dizinidir" gerçekliği, global tanımlı identifier kullanan (`String`, `Promise`…) kaynaklarda semantik tanı → snapshot `state:"partial"` üretir. F6-K3 fixture'ı bu nedenle global-referanssız yazıldı (test dosyasında belgelendi). Güvenlik davranışı ETKİLENMEDİ (yem dışlama tüm durumlarda geçerliydi); F8 docs/backlog'a not düşülmesi önerilir.
2. **"Tek dosya" iddiası:** artefakt tek dosya DEĞİLDİR: `dist/mcp-server.mjs` + `dist/node_modules/better-sqlite3/` (32 dosya) — ADR-010 dürüstlüğüyle raporlanır (native .node gömülemez).
3. **`child_process` varlığı:** bundle'da 2 meşru kullanım vardır — (i) `git-read.ts` salt-okunur git (`execFile`, subcommand allowlist `cat-file`/`ls-tree`, `REF_PATTERN` doğrulaması), (ii) `worker-process.ts` roslyn worker spawn. İkisi de TŞ §19 mitigasyon tablosunun uygulamasıdır; shell interpolation sıfırdır.
4. **URL dizgileri:** bundle metnindeki URL dizgileri dokümantasyon referanslarıdır (modelcontextprotocol spec, aka.ms/tsconfig, RFC'ler, ajv data.json, json-schema `$schema` tanımlayıcıları) — ağ çağrısı kapasitesiyle karıştırılmamalı; runtime sıfır ağ, netguard davranışsal testiyle kanıtlanmıştır. Ölçüm (bu turda): `https://` 59 geçiş / 58 satır / 33 tekil URL, `http://` 21 geçiş — komutlar: `grep -o "https://" <bundle> | wc -l`, `grep -o "https://[a-zA-Z0-9./_-]*" | sort -u | wc -l`, `grep -c "https://" <bundle>`, `grep -o "http://" <bundle> | wc -l`.
5. **Kapsam sınırı:** K6 netguard kanıtı, koşulan oturumların (initialize → tools/list → index → export html → exit) kapsamındadır; bundle'ın tüm olası kod yollarının statik taramasıyla birlikte tamamlayıcı kanıttır.
